# 🌮 Demo Taco Bell Website

## Overview

**Demo Taco Bell Website** is a front-end web development project created as a **BCA Second Semester Mini Project**. The project is a demonstration website inspired by the design and branding of Taco Bell, developed purely for educational and learning purposes.

The objective of this project was to gain practical experience in building modern, responsive web pages using HTML, CSS, and JavaScript while understanding website layouts, navigation bars, image sections, and interactive UI components.

## Technologies Used

### Frontend

* HTML5
* CSS3
* JavaScript

### Design Assets

* Images

* Custom Fonts
